# Admin Panel

## Accessing the Admin Panel

1.  Navigate to the `admin` directory in your web browser (e.g., `http://localhost/tyf/admin/login.php`).
2.  Enter the password `123445678910` and click "Login".

## Features

The admin panel allows you to view:

*   **Contact Form Submissions:** All submissions from the "Short Form Particulars" contact form on the main page.
*   **Newsletter Signups:** All signups from the "JOIN OUR NEWSLETTER" form on the main page.

## Data Storage

The form submissions are stored in the following files in the root directory:

*   `contact_submissions.csv`
*   `newsletter_submissions.csv`

These files are created automatically when the first form is submitted.
